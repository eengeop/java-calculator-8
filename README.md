문자열 덧셈 계산기
==============
***
> ## 프로젝트 개요
> > 사용자로부터 문자열을 입력받아 숫자만 추출하여 덧셈하는 계산기
***
구현 해야하는 기능
----
+ 문자열을 입력 받는 기능
+ 입력 받은 문자열중 커스텀 구분자를 추출하는 기능
+ 입력 받은 문자열에서 구분자와 숫자만 남기는 기능
+ 숫자들만 추출하여 합하는 기능
***
기능 요구 사항 분석
---
* **커스텀 구분자 요구사항 분석**
  + 커스텀 구분자는 문자열이 불가능하다.
  + 커스텀 구분자는 한 개 이상 지정할 수 있다. (ex. //%\n1,2//^\n^3) 
  + 커스텀 구분자는 숫자가 될 수 없다.
  

* **기본 구분자 요구사항 분석**
  + 기본 구분자는 쉼표(,)와 콜론(:)으로 구성된다.
  + 커스텀 구분자를 지정해도 기본 구분자를 사용할 수 있다.
***
예외 처리
---
+ 커스텀 구분자가 문자열이 입력될 경우 예외 발생
+ 커스텀 구분자가 숫자가 입력될 경우 예외 발생
+ 양수가 아닌 숫자가 입력될 경우 예외 발생
***
입출력 요구 사항 분석
---
* **입출력 값은 양의 정수로 정의한다.**
